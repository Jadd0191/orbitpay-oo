# OrbitPay OO

**Motor de pagos y suscripciones orientado a objetos**

## Visión

OrbitPay OO es un motor de pagos construido con Programación Orientada a Objetos en Python puro, guiado por la Metodología Espiral. Este proyecto demuestra la síntesis de 8 competencias clave del módulo 2.
