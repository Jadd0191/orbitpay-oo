# Tarjeta CRC: Cuenta

## Clase
**Cuenta**

## Responsabilidades
1. Mantener el saldo de un usuario
2. Registrar transacciones
3. Gestionar suscripciones
4. Validar que el saldo nunca sea negativo
5. Proveer acceso controlado al saldo

## Colaboradores
1. **Transacción**: Crea y almacena transacciones
2. **Suscripción**: Gestiona suscripciones asociadas
3. **Engine**: Solicita retiros y depósitos
